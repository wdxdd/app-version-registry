# 2026-11-06 ModelBoard 候选版本清单首次公开发布

- 原因：客户端配置的 GitHub Raw 路径实测返回 HTTP 404；ModelBoard 目录仅存在于本地且未被 Git 跟踪。
- 授权：用户明确授权提交并推送 ModelBoard 版本清单，完成线上读取验证。
- 发布范围：仅 ModelBoard 项目目录；不修改其他项目、公共 Schema 或正式渠道版本。
- 候选渠道：iOS / Android 均保持 `1.0.0 (1)`，`storeUrl: null`；正式渠道保持空值，不代表 App 上架。
- 本地验证：现有 AJV 校验 Schema 约束通过（省略该校验器不支持的 draft 声明）；UTF-8 无 BOM、LF、末尾换行通过；客户端现有更新相关测试 3 套 15 项通过。
- 发布后验证：推送后核对远端提交、Raw HTTP 状态及客户端对真实响应的比较结果；真机点击验收另行记录，不以单元测试代替。
