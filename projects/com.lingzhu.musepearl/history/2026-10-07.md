# 2026-10-07 版本信息源与解析契约修复

## 变更

- iOS `releaseCandidate`：`null / null / null` → `1.0.0 / 1 / null`，用于验证“已是最新”。
- 修复客户端读取路径：统一读取 `platforms.<platform>.<channel>`。
- Schema 补齐 `releaseCandidate` 渠道定义。

## 原因

远程 JSON 使用 `platforms.ios.releaseCandidate`，旧客户端错误读取顶层 `ios.releaseCandidate`，导致真机误报“暂无法检查”。
